# Security policy

This project is experimental and validated on Kaspa Testnet-10. It should not be treated as production-ready or mainnet-audited software.

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities involving payment validation, replay handling, settlement, key handling, or mainnet safety.

Use GitHub's private vulnerability reporting / security advisory flow for this repository when available.

Include a minimal reproduction, affected commit, expected impact, and whether the issue was observed on testnet or only identified by inspection.

## Supported scope

Security fixes target the latest `main` branch. Mainnet remains disabled by default and is outside the currently validated deployment scope.
